## Shadcn Integration Notes

### 1. `globals.css` Setup
Copy the values from `colors.shadcn` into your root CSS file to sync the design system tokens with shadcn's components.

### 2. `tailwind.config.js` Setup
To ensure your custom typography and spacing scales are available to shadcn:
* Map `font-sans` to **Public Sans**.
* Map `font-mono` to **Space Grotesk** (for your `label-caps` tokens).
* Ensure `borderRadius.lg` is set to `var(--radius)` to inherit the `rounded.md` (8px) base token defined above.
